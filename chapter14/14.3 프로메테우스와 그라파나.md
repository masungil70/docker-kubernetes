### 프로메테우스(Prometheus)란?

  프로메테우스(Prometheus)는 오픈 소스 모니터링 및 알림 시스템입니다. 원래 SoundCloud에서 개발되었으며, 현재는 쿠버네티스와 함께 클라우드 네이티브 컴퓨팅 재단(CNCF)에 속한 가장 중요한 프로젝트 중 하나입니다.

  쉽게 말해, 시스템과 애플리케이션의 상태를 숫자(메트릭)로 측정하고, 저장하며, 이를 바탕으로 문제를 감지하고 알려주는 도구입니다.

  ---

  주요 특징 및 핵심 개념

  프로메테우스를 이해하기 위한 몇 가지 핵심적인 특징은 다음과 같습니다.

  1. 시계열 데이터 (Time-Series Data)
  프로메테우스는 모든 데이터를 시계열 형태로 저장합니다. 이는 아래와 같은 요소로 구성됩니다.
   * 메트릭 이름 (Metric Name): 측정하는 대상의 이름 (예: http_requests_total - 총 HTTP 요청 수)
   * 레이블 (Labels): 메트릭을 구분하는 key-value 쌍 (예: method="POST", path="/api/users")
   * 타임스탬프 (Timestamp): 데이터가 수집된 시간
   * 값 (Value): 측정된 값 (예: 1024)

  이러한 구조 덕분에 "어떤 API 경로의 POST 요청이 급증했는가?"와 같은 다차원적인 분석이 가능합니다.

  2. 풀(Pull) 기반의 데이터 수집 (Scraping)
  프로메테우스의 가장 큰 특징 중 하나입니다. 대부분의 모니터링 시스템이 각 시스템에서 모니터링 서버로 정보를 밀어넣는 푸시(Push) 방식을 사용하는 반면, 프로메테우스는 주기적으로 대상 시스템에 HTTP 요청을 보내 메트릭을 가져오는(Pull) 방식을 사용합니다.


   * 대상 시스템 (Target): 프로메테우스가 메트릭을 수집하는 대상. 보통 HTTP 엔드포인트(ip:port/metrics)를 노출합니다.
   * 익스포터 (Exporter): 데이터베이스, 하드웨어 등 프로메테우스용 메트릭을 기본으로 제공하지 않는 시스템을 위해, 메트릭을 수집하여 프로메테우스가 가져갈 수 있도록 변환해주는 별도의 에이전트입니다. (예: node_exporter는 서버의 CPU, 메모리 등 시스템 메트릭을 노출합니다.)

  이 방식은 중앙에서 수집 대상을 관리할 수 있어 구성이 간편하고, 대상의 장애 여부를 수집 시점에 바로 파악할 수 있는 장점이 있습니다.

  3. 강력한 쿼리 언어 (PromQL)
  프로메테우스는 PromQL(Prometheus Query Language)이라는 강력하고 유연한 쿼리 언어를 제공합니다. 사용자는 PromQL을 통해 시계열 데이터를 실시간으로 선택, 집계, 연산 및 예측할 수 있습니다.

  예를 들어, 다음과 같은 복잡한 질문에 대한 답을 얻을 수 있습니다.
   * "지난 5분간의 초당 평균 HTTP 요청 수"
   * "CPU 사용량이 80%를 초과하는 모든 인스턴스"
   * "내년 이맘때 예상되는 디스크 사용량"

  4. 서비스 디스커버리 (Service Discovery)
  클라우드 환경(특히 쿠버네티스)에서는 서버나 컨테이너의 IP가 수시로 변합니다. 프로메테우스는 이러한 동적인 환경에 맞춰 모니터링 대상을 자동으로 찾아내고 목록을 갱신하는 서비스 디스커버리 기능을 내장하고 있습니다.

  5. 알림 (Alerting)
  프로메테우스는 단순히 데이터를 수집하는 것을 넘어, 특정 조건이 충족되었을 때 경고를 발생시키는 기능을 포함합니다.
   1. Alerting Rule: PromQL을 사용해 "메모리 사용량이 90% 이상 5분간 지속되면"과 같은 경고 규칙을 정의합니다.
   2. Alertmanager: 프로메테우스 서버가 위 규칙에 따라 경고를 발생시키면, Alertmanager라는 별도의 컴포넌트가 이를 수신합니다. Alertmanager는 중복 알림을 방지하고, 알림을 그룹화하며, 이메일, Slack, PagerDuty 등 다양한 채널로 알림을 라우팅하는 역할을 담당합니다.
