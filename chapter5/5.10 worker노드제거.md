 Worker 노드를 삭제하는 방법 

  이 과정은 크게 두 단계로 이루어집니다.
   1. 컨트롤 플레인에서 노드 정보 제거: 클러스터에게 "이 노드는 더 이상 우리 멤버가 아니다"라고 알리는 과정입니다.
   2. 워커 노드 자체 초기화: 해당 워커 노드에 설치된 쿠버네티스 관련 프로그램을 모두 삭제하여 깨끗한 상태로 되돌리는 과정입니다.

  운영 중인 클러스터라면 서비스에 영향이 없도록 신중하게 진행해야 합니다.

---

  워커 노드 삭제 절차

  1단계: 워크로드 비우기 (Drain) - 컨트롤 플레인에서 실행

  먼저, 삭제할 워커 노드에서 실행 중인 모든 파드(Pod)를 다른 노드로 안전하게 이동시켜야 합니다. 이 과정을 "drain"이라고 합니다.

  마스터 노드에서 아래 명령어를 실행하세요.
```
# <삭제할_워커노드_이름>을 실제 노드 이름으로 바꾸세요.
# kubectl get nodes 명령어로 정확한 노드 이름을 확인할 수 있습니다.

kubectl drain <삭제할_워커노드_이름> --ignore-daemonsets
```
   * --ignore-daemonsets: 모든 노드에 하나씩 실행되어야 하는 DaemonSet 파드는 drain 대상에서 제외하는
     옵션입니다. 이 옵션이 없으면 drain이 실패할 수 있습니다.

  2단계: 노드 삭제 - 컨트롤 플레인에서 실행

  워크로드를 모두 비운 후, 쿠버네티스 클러스터에서 해당 노드의 정보를 완전히 삭제합니다.

  마스터 노드에서 아래 명령어를 실행하세요.
```
kubectl delete node <삭제할_워커노드_이름>
```
  이제 kubectl get nodes 명령어를 실행해 보면, 해당 워커 노드가 목록에서 사라진 것을 확인할 수 있습니다. 여기까지 하면 클러스터에서 노드는 완전히 분리되었습니다.

  3단계: 노드 초기화 (Reset) - 삭제할 워커 노드에서 실행

  이제 삭제했던 워커 노드에 직접 접속하여, 해당 서버에 설치된 쿠버네티스 관련 구성요소들을 모두 삭제하고 초기화합니다.

  삭제할 워커 노드 서버의 터미널에서 아래 명령어를 실행하세요.
```
# root 권한으로 실행해야 합니다.
sudo kubeadm reset -f
```
   * -f (또는 --force): 확인 질문 없이 강제로 리셋을 진행합니다.

  이 명령어를 실행하면 kubelet, kube-proxy 등의 설정과 관련 파일들이 모두 삭제되어, 서버가 클러스터에 참여하기 이전의 깨끗한 상태로 돌아갑니다.
